# Frontend Dashboard - One-Click AI Platform

A modern, high-performance web dashboard for managing the AI platform lifecycle.

## Tech Stack

- **Framework:** Next.js 14 (App Router)
- **Styling:** Tailwind CSS + shadcn/ui
- **State Management:** Zustand
- **Data Fetching:** TanStack React Query
- **Animations:** Framer Motion

## Features

- **Multi-tenant Login:** Secure authentication with organization switching.
- **Dataset Management:** Drag-and-drop uploads and status monitoring.
- **Training Control Plane:** Visual hyperparameter configuration and experiment tracking.
- **Inference Playground:** Side-by-side model comparison mode.
- **Observability:** Real-time metrics visualization.

## Development

```bash
npm install
npm run dev
```

The dashboard will be available at `http://localhost:3000`.
